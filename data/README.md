# 💰 Money Management System (ખાતાવહી / ઉધાર-જમા સિસ્ટમ)

## 📌 ડેટા સ્ટોરેજ અને સિક્યુરિટી (Data Storage & Security Guide)

આ વેબ એપ 100% ક્લાયન્ટ સાઇડ (HTML, CSS, JavaScript) આધારિત છે, જેથી તમે આને **GitHub Pages** પર કોઈપણ સર્વર વગર સીધું જ હોસ્ટ કરી શકો છો.

### 🔒 સિક્યુરિટી (Security Architecture)
1. **GitHub પર ડાયરેક્ટ JSON ફાઈલ કેમ ન મુકવી?**
   - જો તમે સામાન્ય `data.json` માં તમામ વ્યવહારો અને નામો સીધા GitHub પબ્લિક રીપોઝીટરીમાં મુકો, તો ઈન્ટરનેટ પર કોઈ પણ વ્યક્તિ તમારી લિંક ઓપન કરીને તમારા અંગત પૈસાનો હિસાબ જોઈ શકે છે!
   - આથી આ એપમાં **256-bit AES-GCM મિલિટરી ગ્રેડ એન્ક્રિપ્શન** આપવામાં આવ્યું છે.
2. **PIN પ્રોટેક્શન (App Lock):**
   - પહેલી વાર એપ ઓપન કરશો ત્યારે તમારો 4-અંકનો સુરક્ષિત PIN સેટ થશે.
   - તમારો તમામ ડેટા તમારા બ્રાઉઝર સ્ટોરેજમાં PIN વડે એન્ક્રિપ્ટ (કૂટબદ્ધ) થઈને સેવ થાય છે. PIN વગર કોઈ ડેવલપર ટૂલ્સથી પણ વાંચી શકશે નહીં!
3. **બેકઅપ અને JSON ફાઇલ (Export / Import):**
   - એપમાં **"સેટિંગ્સ -> બેકઅપ ડાઉનલોડ (JSON)"** પર ક્લિક કરીને તમે આ `data/` ફોલ્ડરમાં તમારી ફાઈલ સેવ કરી શકો છો.
   - બેકઅપમાં **"Encrypted JSON (સુરક્ષિત)"** વિકલ્પ પસંદ કરવાથી ફાઈલમાં પણ બધો ડેટા એન્ક્રિપ્ટેડ રહેશે, જે તમે ફરીથી ક્યારેય પણ PIN નાખીને ઈમ્પોર્ટ (રીસ્ટોર) કરી શકો છો.

## 🚀 GitHub પર કઈ રીતે અપલોડ કરવું (How to Upload to GitHub Pages)

1. તમારા ગીટહબ (GitHub) એકાઉન્ટમાં નવું Repository બનાવો (દા.ત. `money-management`).
2. આ પ્રોજેક્ટની તમામ ફાઈલો (`index.html`, `css/`, `js/`, `data/`, `assets/`) GitHub Repo માં અપલોડ કરો.
3. GitHub Repo ના **Settings** -> **Pages** માં જાઓ.
4. **Branch** માં `main` (અથવા `master`) સિલેક્ટ કરીને **Save** કરો.
5. 1-2 મિનિટમાં તમને તમારી લાઈવ લિંક મળી જશે (દા.ત. `https://yourusername.github.io/money-management/`).

આ લિંક તમે તમારા મોબાઈલમાં ખોલીને **"Add to Home screen"** કરશો એટલે મોબાઈલ એપ જેવું જ કામ કરશે!
